What is 5-Tuple Hashing?

A 5-Tuple consists of (Src IP, Dst IP, Src Port, Dst Port, Protocol). Your C++ engine computes a hash of this tuple so that all packets belonging to the exact same connection are consistently routed to the same worker thread.

How SNI Extraction Works

Even when HTTPS encrypts packet payload, the TLS Client Hello packet transmits the target domain name in plaintext via the Server Name Indication (SNI) extension. Your DPI engine inspects this header to detect blocked domains before encryption starts!
