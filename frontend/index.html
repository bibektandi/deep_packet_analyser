What is 5-Tuple Hashing?

A 5-Tuple consists of (Source IP, Destination IP, Source Port, Destination Port, Protocol). The C++ DPI Engine calculates a hash of these 5 values so that all packets belonging to the exact same TCP/UDP connection are consistently dispatched to the exact same Fast Path worker thread, preserving state without locking mutexes!

How SNI Extraction Works

Even when HTTPS encrypts web traffic, the initial TLS Client Hello handshake transmits the server hostname in plaintext inside the Server Name Indication (SNI) extension. The DPI engine inspects this header before encryption occurs, enabling precise domain filtering without needing SSL decryption keys!
